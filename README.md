# 🎬 FrameForge – Video Editing Portfolio

FrameForge is a modern and responsive **Video Editing & Social Media Marketing Portfolio Website** designed to showcase creative video editing work and digital content services.

The website provides an interactive portfolio where visitors can browse different types of video edits, preview videos, explore services, and get in touch through the contact section.This project is part of Vaultsofcode internship.

## 🚀 Features

* 🎥 Modern video editing portfolio
* 📱 Fully responsive design
* 🔎 Portfolio category filtering
* ▶️ Video preview modal
* 🎨 Clean and professional UI
* 📋 Services showcase
* 📩 Contact form
* 🔗 Social media links
* 📱 Mobile navigation menu
* ✨ Hover animations and smooth transitions

## 💻 How to Run

This project is a frontend-based website, so no backend or database setup is required.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/frameforge.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the website

You can simply open `index.html` in your browser.

For a better development experience, use the **Live Server** extension in VS Code.

Right-click on `index.html` and select:

```text
Open with Live Server
```

The website will open in your browser.
